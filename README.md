# 🎵 vmlx tv —— 电视大屏音乐 App

> 苹果味儿的壳子 · 落雪（LX）音源的芯 · 手机扫码就能登 Apple Music 📱✨
>
> 基于 [am_atv](https://github.com/Sam20060720/am_atv) 0.6.2 上游改造 · Android TV · Compose · Media3 ExoPlayer

---

## 🌟 它能干嘛

- 📺 **大屏听歌天花板**：横版杂志式界面，遥控器全键盘导航，焦点不迷路
- 🔍 **搜歌超能打**：落雪引擎三平台并发搜索，艺人别名 + 繁简归一，命中率高到离谱
- 🎤 **逐字歌词**：当前行按字逐字点亮，卡拉 OK 内味儿，中文字西文词都能点亮
- 📱 **手机扫码登 Apple Music**：电视出二维码 → 手机扫 → 授权「获取资料库」→ 电视自动登录，「现在收听」和资料库歌单直接用你自己的账号
- 📥 **扫码导入歌单**：QQ 音乐 / 网易云 / 酷狗链接贴一贴，整张歌单进资料库
- 🎧 **软解 / 硬解随手切**：系统解码出杂音？一键切 FFmpeg 软解，歌还在原地续播
- ✍️ **全局苹方字体**：GB2312 子集 1.55MB/字重，又轻又好看
- 🔒 **隐私很干净**：播放全走落雪直链，播放记录**不回传** Apple Music

## 🛠️ 想自己编译？

- **JDK 21** + **Android SDK**，`JAVA_HOME` / `ANDROID_HOME` 配好
- `gradlew.bat :app:assembleDebug` 一键出包（debug 证书，产物在 `app/build/outputs/apk/debug/`）
- 开发者令牌（可选）：`AM_DEVELOPER_TOKEN_FILE` 指向你的 MusicKit JWT，登录链路用它；没有也能跑（落雪播放不受影响）
- ⚠️ **签名警告**：务必保持 debug 证书不变，换签名 = 老用户无法覆盖升级、数据全丢

## 🙏 几句说明

- 音源能力来自落雪（LX）生态脚本，本项目不存储、不分发任何音频文件
- Apple Music 登录仅用于读取你账号的「现在收听」与资料库歌单，播放与播放记录**不经过** Apple
- 上游 [am_atv](https://github.com/Sam20060720/am_atv) 与参考项目 [veil.music](https://github.com/veacon/veil.music) 致谢 🙌
- 字体：苹方（PingFang SC，GB2312 子集化），仅作界面显示用途
